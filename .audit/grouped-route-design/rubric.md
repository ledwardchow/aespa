# Design rubric

Score each criterion 0-4 and explain any missing contract.

1. Prevents all five reproduced defects, including rejected-group query loss, order-dependent access, false Standard completion, and query-object handoff collision.
2. Preserves cheap grouped crawling. Retaining 200 links adds no 200 pages, automatic requests, coverage rows, or specialist jobs.
3. Keeps exact target and identity evidence separate from route display and layout grouping, with unknown ownership and access represented honestly.
4. Gives core callers a small coherent interface with one owner per invariant; avoids a parallel scan engine or duplicated ledgers.
5. Specifies SQLite concurrency/idempotence, old data/archive behavior, scope boundaries, and web/API run separation concretely.
6. Provides realistic usage, type sketch, consumer migration map, and observable tests sufficient to implement without re-deciding key behavior.
